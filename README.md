# Bedtime Virtual Travel Counseling Chatbot using Prompt Engineering

### 🗓️ 2025 Spring Semester Web Programming Term Project

A web-based chatbot that provides users with a relaxing virtual travel experience before bedtime by utilizing prompt engineering techniques with large language models (LLMs). The project aims to help users unwind through interactive travel-themed conversations.
